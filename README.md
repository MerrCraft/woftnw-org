# Wings Of Fire: The New World website

## About

This is a website about the Minecraft Server "WOFTNW"

## Setup (install)

1. Install bun using your Operating System method (see [install bun](https://bun.com/docs/installation))
2. Clone this repository with `git clone https://github.com/WOFTNW/woftnw-org.git`
3. Install depenencies with `bun install`
4. Run `bun dev` to develop, or `bun build` for production.

### Useful bun commands:
- `bun dev`: Starts a development server to develop in.
- `bun preview`: See what the build will look like, before production
- `bun install`: Installs or updates depencencies.
